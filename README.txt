Spoany Studio — 스포애니 신중동점 홍보물 제작 웹앱
====================================================
사이트: https://pueon01-max.github.io/spoany-studio/

■ 쓰는 순서
1) 템플릿 탭에서 템플릿 고르기 (위쪽 포맷 칩으로 피드·스토리·가로·인쇄·X배너 선택)
2) 내용 편집 탭에서 칸 고치기 — 미리보기에서 글자나 사진을 누르면 그 칸으로 바로 이동해요
3) PNG 저장 (▾ 버튼에서 JPG, 인쇄용 3배 선택)

■ 포맷
SNS: 피드 4:5 · 정사각 · 스토리 / 가로: 16:9(매장 TV·유튜브) · 링크 썸네일(블로그·카톡)
인쇄: A4 세로 · A4 가로 · X배너(600×1800mm 비율, 인쇄용 3배 권장)

■ 편집 기능
- 레드 강조: 글자를 드래그하고 '강조' 버튼 (또는 *단어*처럼 별표로 감싸기)
- 목록: ＋추가, ↑↓ 순서 바꾸기, ✕ 삭제, ☆ 강조(가격표의 BEST 행)
- QR 코드: 링크를 넣으면 쿠폰·공지·가격표·X배너에 QR이 생겨요
- 되돌리기/다시(Ctrl+Z / Ctrl+Shift+Z), 자동 저장, 보관함(이름 붙여 저장·불러오기)
- 자동 저장과 보관함은 이 기기·이 브라우저에만 저장돼요

■ Claude로 자동 제작 (선택)
AI 제작 탭 > Claude API 설정에 console.anthropic.com에서 발급한 키를 넣고 저장.
키는 이 기기 브라우저에만 저장되고 코드에는 들어가지 않아요. 사용 요금은 키 계정에 청구돼요.

■ 휴대폰에 설치
아이폰 Safari: 공유 → 홈 화면에 추가 / 안드로이드 Chrome: 메뉴 → 앱 설치

■ 코드 구조 (수정하는 사람용)
src/ 폴더가 원본이에요. 고친 뒤 `python3 build.py`를 실행하면 index.html, fonts/, vendor/가 만들어져요.
- src/templates.js  포스터 템플릿
- src/app.js        편집기·저장·보관함·AI
- src/ui.css, src/poster.css, src/shell.html
- src/platform.web.js / platform.claude.js  웹앱용·claude.ai용 차이
