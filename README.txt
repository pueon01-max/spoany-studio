Spoany Studio — 스포애니 신중동점 홍보물 제작 웹앱
====================================================

폴더 구성
- index.html ............ 앱 본체 (템플릿 17종, 편집, PNG 저장)
- manifest.webmanifest .. 홈 화면 설치 정보 (이름, 아이콘)
- sw.js ................. 오프라인 실행용 (한 번 열면 인터넷 없이도 열림)
- fonts/ ................ Pretendard, Inter Tight (앱 안에 내장 → 저장 PNG가 화면과 똑같이 나옴)
- icons/ ................ 앱 아이콘
- html-to-image.js, html2canvas.min.js ... PNG 저장 엔진

※ 폴더 안 파일 구조를 그대로 둔 채 통째로 올려야 합니다.


1. 인터넷 주소로 올리기 (가장 쉬운 방법: Netlify Drop)
------------------------------------------------------
1) https://app.netlify.com/drop 접속 (무료 가입)
2) 압축을 푼 spoany-studio 폴더를 화면에 그대로 끌어다 놓기
3) 몇 초 뒤 https://○○○.netlify.app 주소가 생김 → 끝
   - 수정본을 올릴 때는 같은 사이트의 Deploys 탭에 폴더를 다시 끌어다 놓기

다른 방법: GitHub Pages
- GitHub에 새 저장소를 만들고 폴더 안 파일을 모두 업로드
- Settings → Pages → Branch: main / root → Save
- https://아이디.github.io/저장소이름/ 주소로 열림


2. 휴대폰에 앱처럼 설치하기
--------------------------
- 아이폰: Safari로 주소 열기 → 공유 버튼 → "홈 화면에 추가"
- 안드로이드: Chrome으로 주소 열기 → 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
- 설치 후에는 주소창 없이 앱처럼 열리고, 오프라인에서도 편집·PNG 저장이 됩니다.


3. Claude로 자동 제작 쓰기 (선택)
--------------------------------
1) https://console.anthropic.com 에서 API 키 발급 (결제 수단 등록 필요, 쓴 만큼 과금)
2) 앱 왼쪽 "Claude API 설정"에 키를 붙여넣고 저장
3) "무엇을 만들까요?"에 요청을 쓰고 "Claude로 제작"
   - 모델: Sonnet 5.5(기본) / Haiku 5.5(빠르고 저렴) / Opus 5.5(가장 꼼꼼)

보안 안내
- 키는 앱 코드에 들어가지 않고, 키를 입력한 그 기기의 브라우저에만 저장됩니다.
  → 사이트 주소를 남에게 알려줘도 내 키는 노출되지 않아요. 다른 사람은 자기 키를 넣어야 씁니다.
- 공용 PC에서 썼다면 "키 지우기"를 눌러 주세요.
- 키 없이도 템플릿 선택, 내용 직접 수정, 사진 넣기, PNG 저장은 모두 됩니다.


4. 저장
------
- PNG 저장은 2배 해상도(피드 기준 2160×2700)로 저장됩니다.
- 휴대폰에서는 공유 시트가 열려 바로 사진 앱에 저장하거나 인스타에 공유할 수 있어요.
- 사진은 기기 안에서만 처리되고 어디에도 업로드되지 않습니다.
